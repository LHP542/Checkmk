Zwei Änderungen an der Standortkarte. Kein Datenbank-Eingriff nötig — Schema 9
wie in 1.20.1.

## Rechtsklick auf einer Fläche beendete die App

```
FATAL|Program|App wurde durch eine Ausnahme beendet.
Cannot show ContextMenu on a different control to the one it is attached to.
```

Das Kontextmenü der Karte hing am umgebenden Layout-Element, geöffnet wurde es
aber auf der Karte darin. Avalonia lässt ein Menü nur auf genau dem Element
öffnen, an dem es hängt — und weil das beim Klick auffliegt, nicht beim Bauen,
war jeder Rechtsklick auf einem Standort ein Absturz.

## Die Karte hat kein eigenes Kontextmenü mehr

Ein Klick auf eine Fläche oder einen Marker — **links wie rechts** — markiert
den Bereich, und zwar auch im Baum links. Die Aktionen dazu stehen im
Kontextmenü des Baums.

Das Kartenmenü war eine inhaltsgleiche Zweitausgabe davon. Zwei Menüs an zwei
Stellen zu pflegen kostet mehr, als der gesparte Blick nach links einbringt —
zumal die Auswahl beim Klick ohnehin mitspringt und der Standort im Baum damit
schon markiert ist.

Im Bearbeitungsmodus einer Fläche bleibt der Rechtsklick unverändert die
Ecken-Entfernung.
